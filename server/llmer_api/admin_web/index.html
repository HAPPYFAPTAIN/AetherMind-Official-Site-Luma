新版导入格式与示例

接受本次两个 XLSX 的原始格式，最大8MB。HumanBench 工作表名为“HumanBench题库”，第1行按顺序填写：题目ID、来源分类、子分类、题干/用户输入、选项1、选项2、选项3、选项4、选项5、题目说明、选项信息(JSON)、其他元数据(JSON)、素材类型、素材键、素材原始数据。保留“破冰100题”“48项后缀规则”“审核台账”。真题工作表名为“真题题库”，保留题目ID、分类、类型、题干、A选项至D选项、正确答案、解析、来源，表头可在第4行。

选项信息(JSON)：[{"id":"q1-a","t":"选项文本","ok":1,"r":"正确依据"}, ...]
其他元数据(JSON)：{"scored":true,"primaryDimension":"C","lv":1,"duplicateFamilyId":"family-example","governanceRole":"main_candidate","reviewStatus":"pending","deploymentEligible":false}

正式能力题四选一，只允许一个正确选项；维度C/R/D/G/A/K/W/X，难度1至4。题族、曝光互斥组与审核状态会保留。来源题缺字段不会自动补分或升格。审核通过与可投放需同时满足；待审核新题只用于标明的试测。导入先生成待启用版本，确认启用时再次校验组卷，历史已发题卷不变。QS真题只做不计分练习，NS风格独立计算。

JSON 上传格式（可直接照着改）

不需要下载示例。把下面任一示例复制到本地保存为 UTF-8 的 .json 文件，再在上面选择上传；一次文件只上传一种题型。

1. 计分题：四选一

{
  "kind": "assessment",
  "version": "assessment-json-1.0.0",
  "sources": [{"id": "SRC-DEMO-001", "label": "自编题"}],
  "questions": [{
    "id": "C-A-001", "pool": "anchor", "dimension": "C", "difficulty": 1,
    "scene": "会议改期", "prompt": "会议临时改到下午，你会怎么确认？",
    "options": [
      {"id": "O1", "label": "确认时间、地点和后续安排。", "score": 3},
      {"id": "O2", "label": "只回复收到。", "score": 2},
      {"id": "O3", "label": "等对方再次通知。", "score": 1},
      {"id": "O4", "label": "按原时间到场。", "score": 0}
    ],
    "sourceRefId": "SRC-DEMO-001", "status": "candidate/draft"
  }]
}

计分题字段：pool 填 anchor、standard 或 challenge；dimension 填 C/R/D/G/A/K；四个选项分值必须各为 0、1、2、3。

2. 减压题：脑筋急转弯 A/B

{
  "kind": "relaxation",
  "version": "relaxation-json-1.0.0",
  "declaredCount": 1,
  "questions": [{
    "id": "REL-001", "category": "身份反转型", "type": "脑筋急转弯",
    "scored": false, "prompt": "大象的左耳朵最像什么？",
    "options": [
      {"id": "A", "label": "扇子", "vibe": "常规联想"},
      {"id": "B", "label": "它的右耳朵", "vibe": "就地取材"}
    ],
    "explanation": "答案就在题目旁边。", "status": "active"
  }]
}

减压题不计分，必须使用 REL- 编号、scored:false 和 A/B 两个选项；分类只能是身份反转型、谐音梗型、生活常识反杀型、无厘头脑洞型、终极送分型。

字段格式、示例与出题规则

推荐使用模板的“题库”工作表，第 1 行为表头，第 2 行开始填写，每行一道题。也支持 JSON 上传（格式见上方示例）、“轻松题库 / 挑战题库”（表头第 4 行）及“来源与版权台账”的原始 V1.1 格式。支持 XLSX 或 JSON，最大 4MB，一次最多 2000 道题；不执行公式或宏。计分题 JSON 示例是字段片段，实际导入仍需补齐各维度和题池的最低数量。

字段示例 / 规则
题目IDC-A-001，版本内唯一；仅字母、数字、点、横线、下划线，不能以 ICE- 开头
题池anchor（共同） / standard（轻松） / challenge（挑战）
维度C 语境承载 / R 结构推理 / D 信息压缩 / G 迁移生成 / A 对象适配 / K 校准修正
难度 / 场景 / 题干难度数字 1、2、3；场景和题干必须填写
O1文本 / O1分 … O4文本 / O4分四个不同选项；每题 0、1、2、3 分各一次，分值是数字，不能填公式
来源ID / 公开署名 / 来源URLSRC-001 / 自编题 / https://…；来源URL可空，原版台账须有匹配来源
前置信息 / facet / 状态前置信息可空，有值则并入题干；facet 可填 privacy_boundary / uncertainty 等；状态默认 candidate/draft，retired 不参与抽题
O1新颖度 … O4新颖度可选 0 至 3，影响温度；相同 ID 与相同选项文本沿用原 style，否则默认 1.5，不根据分数猜风格
计分权重可选，大于 0 且不超过 3。原题 ID 且题池/维度相同沿用已有权重；新题默认 1，不因挑战或购买自动加分

服务器生成整轮题单：每维抽 2 道 anchor + 1 道对应模式题，共 18 道计分题。破冰题固定在第 1、2、8、14、20、24 题，每类每轮只出一次，优先避开最近 5 轮已出的题。选项顺序与整轮题单一起冻结；重试/继续不会换题。购买不会改分数。每个维度至少 2 道共同、1 道轻松、1 道挑战题才允许导入完整题库。

“安全过滤器与对齐”可作为题目场景/facet，“幻觉与自信校准”可归入 K 维度内容；本次保留六维计分结构。连续前屏信息会合并成独立题目，不把它误计为跨题记忆证据。

导入不会覆盖旧版本。相同内容重复导入复用版本；启用旧版本可回退后续出题。候选题的状态会保留，启用体验题库不代表已经完成科学量表校准。

减压题库格式

可直接上传《LLMer_减压题库32道与台账_V1.0.xlsx》同格式文件：工作表名“减压题库”，表头在第 1 至 5 行。一行一题，题目ID为 REL-001 这样的编号，“类型”填脑筋急转弯，“是否计分”必须填否。

必需字段：题目ID、分类、类型、是否计分、题干、A选项（陷阱）、A风格标签、A新颖度、A温暖度、A直接度、B选项（正确）、B风格标签、B新颖度、B温暖度、B直接度、笑点解析。六个风格数值为 0 至 3，不计入测评分数；表内字数等公式列不参与导入。

分类：身份反转型、谐音梗型、生活常识反杀型、无厘头脑洞型、终极送分型。减压题混入现有破冰流程，每套固定 18 道计分题 + 5 道原破冰题 + 1 道减压题，共 24 道。原破冰题从既有 100 道中抽取；减压题从启用的减压题库抽取，随机放在第 8、14、20 个位置之一，每类每轮最多一次。A/B 顺序保留，选答后展示解析，不评判测评能力。总览与实际题数不一致会明确提示，以实际题目为准。待修订内容保留记录但不投放。

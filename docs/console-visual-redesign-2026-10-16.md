# 控制台视觉改造说明

日期：2026-10-16

## 展示层修改

控制台保留智能体目录、超算连接、计算任务三个原有分区。增加页面标题与说明，统一导航图标、字号、间距、按钮主次和亮暗配色。MD EXP 作为主要工具展示，另外三个智能体继续保持未开放及不可点击状态。未使用虚构的任务数量、运行指标或账户权益作为装饰。

修改文件为 `src/components/ConsolePage.tsx`，新增样式文件为 `src/components/console-workspace.css`。图片使用现有主题素材，不新增媒体下载来源。

## 原有业务逻辑保持不变

改造前保存了当前组件副本，并逐字比较从 `useEffect` 到侧栏数据声明之间的代码，以下内容完全一致：

- 账户会话检查和 `/md-agent/profile` 加载。
- 未登录时前往原登录地址，保留原有 returnTo。
- `md-exp` 产品资格判断及无资格时的提示。
- `/md-agent/bind`、`/md-agent/enter` 的调用顺序、参数、请求方式。
- 新窗口预留、成功跳转、错误关闭及加载状态处理。
- 退出登录及其跳转。

账户客户端与账户 Hook 文件另外进行改造前后 SHA-256 核对。没有修改后端接口、数据库、权限、产品资格、订单或支付逻辑。侧栏切换、登录弹窗开关和智能体按钮的禁用条件继续使用原处理逻辑。

## 页面导航变更

原“联系客服”按钮没有绑定点击处理，改为普通链接 `/enterprise/#contact`，通过现有 `assetUrl` 添加站点基础路径。它只打开已有联系区域，不发送消息、不提交信息，也不调用新接口。

新增侧栏“联系团队”“浏览产品”和页头“返回官网”均为现有页面链接。未新增需要后端支持的功能。

## 验收范围

生产构建、TypeScript 及组件 ESLint 检查通过。已在浏览器验证亮暗外观、桌面和 390px 手机布局、三个侧栏分区切换、登录弹窗打开与关闭、三个未开放按钮的禁用状态、全部配图加载以及联系入口地址。手机主操作按钮约 52px 高，页面没有横向溢出。账户客户端与账户 Hook 的 SHA-256 核对一致。

此轮未触发真实产品进入、资源绑定、任务提交或退出登录等账户操作；业务处理代码以逐字比较及文件哈希核对验证未变。

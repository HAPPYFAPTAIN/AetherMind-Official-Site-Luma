# 外观与页面引导改动说明

日期：2026-10-16

## 范围

本轮修改非首页页面的亮暗主题、主题配图、字号、间距、按钮样式和内容分区。首页保持深色展示。企业服务页的主按钮指向现有联系区域，次按钮指向服务介绍，三个服务入口指向各自的页面内锚点。

## 接口与业务逻辑

- 不新增或修改后端接口、请求参数、响应格式、认证头或 Cookie。
- 不修改登录、短信验证、管理员授权、产品权限、购买、订单或支付逻辑。
- 不修改数据库结构、服务器配置或线上部署。
- 企业服务页按钮使用原生链接跳转，不提交表单、不创建订单、不发送联系消息。
- 现有工作区包含此前已要求的产品详情页及导航跳转修改；这属于较早的独立工作，不是本轮主题设计新增的接口变更。

核对时，`src/lib`、`src/app/api`、`server`、`prisma`、`backend` 路径相对当前 Git HEAD 没有差异。登录、控制台及个人页中本轮插入的主题按钮仅改变外观，原有事件处理与业务请求保持不变。工作区含其他未提交修改，以上保证限定于本轮外观修改，不代表对所有历史修改的业务审计。

## 新增的纯展示交互状态

### 外观偏好

实现文件：`src/components/ThemeProvider.tsx`、`ThemeSwitch.tsx`。

- 三种选择：跟随系统、亮色、深色。首次访问默认跟随系统。
- 浏览器本地键名 `aethermind-theme`，值为 `system`、`light` 或 `dark`。不上传服务器，不关联账号，不影响权限。
- 通过系统 `prefers-color-scheme` 跟随外观变化。同源标签页同步本地偏好；不同域名分别保存。
- 首页始终显示深色，但保留用户偏好用于其他页面。
- 切换时以约 320 毫秒渐变颜色与图片；系统要求减少动态效果时取消渐变。
- 移动端使用紧凑按钮依次切换模式，按钮的无障碍名称说明当前及下一种模式；桌面端可直接选择三种模式，并支持方向键。

### 服务咨询提示

企业服务页点击某项服务的咨询入口时，页面内临时记录所选服务，并在联系人区域展示对应的沟通准备提示。此状态只存在于当前页面内存，不持久化、不请求后端、不提交咨询记录，也不改变产品、账号或订单状态。此项为展示引导逻辑，特此单独说明。

## 图片

亮色版本放在 `public/images/theme-light/`，深色原图保留。图片仅用于展示，不替换计算结果、产品数据或真实任务状态。9 组亮色图片有 640px 与 1536px 两种尺寸，采用 WebP。

## 验证与限制

- 生产构建、TypeScript 检查通过。
- 主题、企业服务页面相关组件的 ESLint 检查通过。
- 浏览器检查主题切换、页面内按钮定位、图片加载与移动端布局。
- 本地静态预览不提供后端 API，因此本轮不以真实登录、购买或权限变更作为视觉验收步骤。

如后续确实需要接口或业务逻辑变更，应另列接口路径、参数、响应、权限边界、兼容方式及验证步骤，本轮不实施这些变更。

# 项目功能

> 功能范围与当前状态的唯一清单。API、数据模型和函数级设计放在项目设计文档中并从此处引用。

## 状态定义

- 候选：尚未批准进入范围
- 已规划：已确认但未开始
- 进行中：正在实现
- 已阻塞：等待外部条件
- 已完成：完成条件满足且有证据
- 已取消：退出范围并保留原因
